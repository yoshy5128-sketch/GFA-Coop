# GUNFIGHT ARENA CO-OP

既存のGunFightArenaを維持したまま、2人協力プレイを追加する独立開発版です。

## 開発状態

- GFAシングルプレイ本体を独立リポジトリへ移行済み
- WebSocketシグナリングとWebRTC DataChannel接続を実装済み
- 高速状態用（非順序・再送なし）と重要イベント用（順序保証）の2チャンネルを分離
- DUALTANK v0.4.9のシグナリング切断誤判定対策を継承
- ゲーム状態・リモートプレイヤー同期は次フェーズ

## ローカル起動

```sh
npm install
npm start
```

ブラウザで `http://localhost:3000` を開き、タイトル画面の `LAN CO-OP` から接続します。2台の端末で試す場合はHTTPS公開環境を使用してください。

### CO-OP初期プレイ版

1. 2台で同じルームコードを使い、HOST / PLAYER 1とGUEST / PLAYER 2として接続します。
2. `P2P接続成功・双方向通信確認済み`の表示後、HOST側の`HOSTからCO-OPを開始`を押します。
3. HOSTの設定で両端末が開始し、Player 2は少し離れた位置へスポーンします。

現在の初期プレイ版はDefault Mapで、プレイヤーの位置、向き、移動、しゃがみ、装備武器、射撃演出を同期します。敵AIの位置、向き、姿勢、武器、HPはHOSTからGUESTへ同期します。ダメージ、アイテム、勝敗の完全なホスト権威同期は次段階です。

## Vercel

`vercel.json`が静的配信物を`dist`へ生成し、`/p2p-signal`をVercel WebSocket Functionへ接続します。GitHubの`main`へpushするとVercel側で再デプロイされます。

Vercel Functionsでは、新しいWebSocket接続が同じ関数インスタンスへ到達する保証がありません。そのため、公開版はRedisで部屋の在室情報とoffer/answer/ICEを中継します。

### 公開CO-OPに必要なRedis設定

1. VercelプロジェクトのStorage / MarketplaceからUpstash Redisを追加します。
2. GFA-Coopプロジェクトへ接続し、接続文字列を`REDIS_URL`としてProduction、Preview、Developmentへ公開します。接続時のプレフィックスを`STORAGE`にした場合の`STORAGE_URL`にも対応しています。
3. 最新コミットをRedeployします。

`REDIS_URL`と`STORAGE_URL`のどちらもない公開環境では、両プレイヤーを待機させ続けず、CO-OP画面へ設定不足を表示します。ローカルの`npm start`は従来どおり単一プロセス内のルーム管理で動作します。

## Original GUNFIGHT ARENA

GunFightArenaへようこそ!!

面倒なことは一切抜きで、今すぐ撃ち合いを始めたい！
全員が敵のFreeForAllをはじめ、AIを相手に1V3から2V2のTeamDeathmatchまで、存分にGunFightが楽しめるシンプルかつ超エキサイティングなFPS。それがこのGunFightArenaだ！
AIを舐めたら殺られるぞ！奴らは物陰に隠れて攻撃してきたり、待ち伏せはもちろん、塔に上がって狙撃してくる！

ローポリな見た目ながら、バトルではさまざまな設定が可能！

・プレイヤーと敵AIのHPをそれぞれ変更可能。無敵モードも可。
・プレイヤーのデフォルト武器と敵AIのデフォルト武器をそれぞれ選択可。デフォルト武器は弾数無制限（但しReloadあり）
・ProjectileSpeedで弾の速さを可変できる。
・Character Editerでキャラの容姿をカスタマイズ可。
・WeaponCountでアリーナ内に配置できる各武器の数を可変できる。武器は取った後も復活。但し、装備できる武器は1種類のみ。異なる武器を拾うことでチェンジできる。弾を撃ち尽くすまでReloadは不可。
・Medikitは、アウトドア・1V3モードとインドア・コンバットモードのみで有効。取得することでHPが回復する。アリーナに配置する数も可変できる。
・AICountで敵AIの数を変更可能。尚、チームデスマッチでは、AI（Enamy1）が1体味方となり2V2となる。
・強力なMap Editerで自作のオリジナルマップをゼロから作成可。自作のマップデータを.jsonとして保存＆読み込み可。
・ランダムマップで今すぐに新しいマップを作成可能。Map Editer上であれば、そのマップを自在に調整可能。
・NightModeは、暗闇での夜戦モード。LightIntensityでアリーナの明るさを調整できる。
・ButtonSettingでスマートフォンのボタン位置調整が可能。ゲーム中に★マークを押し、ポーズONで位置を調整できる。
・チームデスマッチでは、Followモードあり。味方AIがプレイヤーの側で常に追従して援護、攻撃をする。
・INDOOR COMBATは室内戦。部屋のサイズや明るさを可変できる。AIはすべて敵だが、チームデスマッチでは、AI1体が味方となる。
・爆発物（ドラム缶）を破壊することで近くの敵をキル可能。爆発物同士は誘爆する。
・障害物や建物も規定数の爆破回数で破壊可能。

■スマホでの操作：画面左半分＝前後左右移動　画面右半分＝始点移動　各種ボタン＝攻撃、しゃがみ、フォロー　★ボタン＝ポーズ&設定画面　×＝狙撃解除（スコープ画面内左）
■PCでの操作：W=前進　S＝後進　A=左移動　D＝右移動　P=ポーズ&設定画面　F=AIフォロー　C＝しゃがむ　マウス＝視点移動　左クリック＝武器発射　右クリック＝狙撃解除　Esc/★ボタン＝ポーズ&設定画面
